# VeriCraft: Transparent Supply Chain Proof of Origin for Artisan Goods

VeriCraft is a full-stack Ethereum blockchain application built with **Solidity**, **Hardhat**, and **Vanilla HTML5 / CSS3 / JavaScript** (Ethers.js v6 + QRCodeJS via CDN, zero TypeScript or bundler dependencies).

## Show Live Demo on GitHub Pages

Because VeriCraft includes an **Interactive Demo Ledger** fallback when no local Hardhat node is running, your pushed GitHub repository runs directly as a live web demo on GitHub Pages:

1. Push the latest files (`index.html`, `.nojekyll`, `.github/workflows/pages.yml`, and `frontend/`) to your GitHub repository.
2. Open your repository on GitHub and go to **Settings → Pages**.
3. Under **Build and deployment → Source**, pick **either**:
   - **GitHub Actions** (recommended — automatically publishes `./frontend/` at `https://<your-username>.github.io/<your-repo>/`), **or**
   - **Deploy from a branch** → choose `main` and `/ (root)`.
4. Open your published `github.io` link. Visitors can browse verified crafts, inspect timelines, click **Connect Wallet** to test Artisan minting, Custody Handoffs, and Admin verification with zero local setup.

## Windows PowerShell Quick Start

Open three PowerShell terminals inside the `VeriCraft/` folder:

### Terminal 1 — Install Dependencies & Start Local Hardhat Blockchain
```powershell
npm install
npx hardhat compile
npx hardhat node
```

### Terminal 2 — Deploy Contract & Seed Demo Data
```powershell
npx hardhat run scripts/deploy.js --network localhost
```
This deploys `VeriCraft.sol`, seeds **Ramesh Kumar** (verified artisan) and **Product #1: Handcrafted Rosewood Elephant** with 2 provenance checkpoints, and automatically generates `frontend/contractConfig.js`.

### Terminal 3 — Launch Frontend Server
```powershell
npm run dev
```
Open `http://localhost:3000` (or `http://localhost:3000/?id=1`) in your browser.

### Optional MetaMask Configuration (Localhost 8545)
- **Network Name:** Hardhat Localhost 8545
- **RPC URL:** `http://127.0.0.1:8545`
- **Chain ID:** `31337`
- **Currency Symbol:** `ETH`
- Import one of the private keys printed by `npx hardhat node` (Account #0 is Admin, Account #1 is Verified Artisan, Account #2 is Retail Hub Handler), or use the built-in **Local Hardhat Signer** selector in the Wallet Bar for quick local testing.
